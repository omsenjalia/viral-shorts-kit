# Sound effects

All files here are CC0 (public domain), safe for monetized YouTube.

- `*.ogg`: [Kenney](https://kenney.nl/) audio packs, via the curated set in [latent-spaces/brag](https://github.com/latent-spaces/brag)
- `key-*.wav`: [Keyboard Soundpack #1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes) by unicae_games

| Name | Use |
|---|---|
| hit | hook impact, signature wipe |
| thud | heavy reveal |
| bell | logo / end card payoff, a stat landing |
| pop | text fragment landing |
| click / send | UI press, chat send |
| switch | list item, toggle |
| slide | card or panel arriving |
| count | counter rolling |
| glitch | rare "AI" accent |
| key-* | typing (thinned, randomised) |
